loco task runner

Queue coding-agent cycles against a local workspace. By default only {{ max_concurrent }} run at a time; extra tasks wait. Parallel runs on this machine will fight over CPU, RAM, and the model server.

Pick a remembered host or type a new one (host:port or /v1 URL). Used servers are saved for the next restart.

A running cycle calls the model, edits files, and runs the project’s tests. Start another only if you accept the slowdown.
